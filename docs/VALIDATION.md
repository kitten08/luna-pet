# v1.3.1 验证记录

- 动作目录仅有 20 项。四套衣服各包含 20 个文件，合计 80 条透明 WebM。
- 每条解码为 200 帧。核对了每套服装的代表帧和动作姿势。
- 日常装保留的 8 条原片与批准版本 SHA-256 完全一致。
- 四套服装分别验证入睡末帧、循环首尾、醒来首帧的 RGBA 一致。入睡首帧和醒来末帧一致。
- 原有入睡、醒来及新增姿势使用插画补间，动作跨度较大的短暂过渡可能有轻微重影。
- 本地测试验证播放匹配当前服装、睡眠接续、点击回应轮换和拖拽释放后的状态清理。

详细文件哈希和接点记录见 [媒体验收记录](motion-release.json)。
